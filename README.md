# Calculate and Print Student Grades

This is a beginner-level C# project based on Microsoft Learn.

## 📌 Description
This project calculates the total scores and average grades of students using basic variables and arithmetic operations.

## 🛠️ Technologies Used
- C#
- .NET (Console Application)

## 🚀 Features
- Calculates total marks of each student
- Computes average grades
- Displays formatted output in console

## 📚 Learning Purpose
This project is part of my C# learning journey. It focuses on:
- Variables
- Data types
- Arithmetic operations
- Output formatting

## ⚠️ Note
This version does not use arrays or loops. It is a basic implementation for learning purposes.
